# Роды и восстановление — платформа курсов

Три курса («Подготовка к родам», «Роды», «Восстановление после родов»), продаются по отдельности или пакетом. Оплата — GetPlatinum, видео — Кинескоп, вход в личный кабинет — по email и паролю, который покупатель придумывает после оплаты.

## Оплата и вход

1. Покупатель вводит только email. Сайт создаёт аккаунт без пароля и просит у GetPlatinum страницу оплаты по предложению из кабинета (`lib/getplatinum.ts`, метод `init-payment-url-by-offer`; номера предложений — в `lib/config.ts`). Цена берётся из предложения; если она не совпадает с ценой на сайте, заказ не оформляется.
2. Письмо после оплаты отправляет GetPlatinum: его текст — поле «Материалы для покупателя» в каждом предложении.
3. GetPlatinum присылает подписанное уведомление на `/api/webhooks/getplatinum` (HMAC-SHA256 тела запроса с API-ключом, заголовок `X-Checksum`), и курс (или все три для пакета) открывается автоматически.
4. Сразу после оплаты покупателя возвращает на `/order/success` (секрет заказа в ссылке), где он придумывает пароль. Если не успел — страница «Первый вход» (`/first-login`) для аккаунтов с оплатой и без пароля.
5. Забыл пароль — поддержка (ссылка в `lib/config.ts`). Админ (`users.is_admin`) на странице `/admin` сбрасывает пароль по email, после чего человек снова проходит «Первый вход».

Переменная окружения в Vercel: `GETPLATINUM_API_KEY` — ключ из GetPlatinum («Настройки» → настройки организации → API-ключ).

Ссылка на чат курса (кнопка «Перейти в чат курса» в кабинете) хранится не в коде, а в таблице `site_settings` под ключом `chat_url`: репозиторий публичный, и приглашение не должно в нём светиться.

Выдать доступ вручную (например, при оплате вне сайта):

```bash
PAID_EMAIL=buyer@example.com PAID_PRODUCT=rody npm run mark-paid
```

`PAID_PRODUCT` — slug курса (`podgotovka-k-rodam`, `rody`, `vosstanovlenie`) или `bundle`. Код под Продамус (`lib/prodamus.ts`, `/api/webhooks/prodamus`) не используется.

## Стек

Next.js (App Router) + TypeScript + Tailwind + Neon (Postgres, `@neondatabase/serverless`, без ORM). Тот же подход, что и в [`learning-tracker`](../learning-tracker).

## Настройка

1. Скопировать `.env.local.example` в `.env.local` и заполнить:
   - `DATABASE_URL` — строка подключения к Neon Postgres
   - `AUTH_JWT_SECRET` — `openssl rand -hex 32`
   - `PRODAMUS_SHOP_DOMAIN`, `PRODAMUS_SECRET_KEY` — из личного кабинета Продамус
2. Применить схему БД и наполнить демо-контентом:
   ```bash
   npm run db:migrate
   npm run db:seed
   ```
3. Запустить дев-сервер:
   ```bash
   npm run dev
   ```

## Структура

- `app/` — публичный лендинг, страницы курсов, чекаут, личный кабинет
- `lib/` — доступ к БД (`queries.ts`), сессии и пароли (`auth.ts`), интеграции (`prodamus.ts`)
- `db/schema.sql` — схема БД
- `scripts/seed.ts` — демо-наполнение курсов/модулей/уроков/материалов

⚠️ Точные названия полей и подпись webhook'а Продамуса в `lib/prodamus.ts` нужно свериться с личным кабинетом конкретного магазина перед запуском реальных платежей.
